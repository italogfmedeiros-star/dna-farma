# Atas de Reunião

Registros de reuniões dos ritos definidos na Seção 5.3 do documento mestre (Daily, Weekly, Comitê Editorial, Comitê Executivo, War Room, Retrospectiva de fase).

## Convenção de nome de arquivo

`AAAA-MM-DD-nome-do-rito.md`

Exemplo: `2026-08-11-comite-editorial-01.md`

## Template sugerido

```markdown
# <Rito> — <data>

- **Participantes:**
- **Pauta:**
- **Decisões tomadas:** (linkar para `_decisoes/DEC-0XX.md` se aplicável)
- **Bloqueios levantados:**
- **Próximos passos:**
```
