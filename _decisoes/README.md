# Registro de Decisões (DEC-xxx)

Fonte de verdade atual: tabela consolidada em [`../00-projeto-mestre.md`](../00-projeto-mestre.md), Seção 12.

**Regra (Seção 5.4 do documento mestre):** toda decisão vira registro `DEC-xxx` e não é reaberta sem novo registro. Alterações exigem novo registro com justificativa e análise de impacto.

## Convenção

Quando uma decisão pendente for tomada, criar aqui `DEC-0XX-titulo-curto.md` com:

```markdown
# DEC-0XX — <título>

- **Data:**
- **Responsável:**
- **Status:** Vigente
- **Contexto:**
- **Decisão:**
- **Justificativa:**
- **Impacto:** (tarefas/fases afetadas)
```

Depois, atualizar a linha correspondente na Seção 12 do `00-projeto-mestre.md`.
